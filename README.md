# Pokemon-Ado.net – Crud

Este proyecto fue mi primer app de escritorio desarrollada en **C#**, es un crud con conexion a base de datos **SQL**.

## 💻 Funciones

El administrador puede:  
- Visualizar, buscar y filtrar artículos según sus properties(nombre/numero/descripcion/etc).  
- Editar, agregar y eliminar en la base de datos **SQL Server**.  
- Acceder a una vista tipo GridView con todos los Pokemons listados.
- Utilizar un filtro extra, donde puede hacer consultas mas avanazadas o especificas.
